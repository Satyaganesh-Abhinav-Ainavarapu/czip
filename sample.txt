C-ZIP is a concurrent file compression utility designed
to demonstrate operating system concepts such as memory
mapping, multithreading, synchronization and parallel
processing. The input file is divided into fixed-size
chunks and each chunk is processed independently by a
worker thread. A bounded work queue is used to safely
transfer chunks between the producer and worker threads.
The compression engine uses the DEFLATE algorithm to
compress each chunk independently.
