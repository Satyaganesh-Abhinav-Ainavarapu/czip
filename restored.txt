ConcurrentZip (C-ZIP) is a user-space, multi-threaded command-line compression utility designed to demonstrate operating-system concepts through a concurrent compression pipeline. The overall design divides an input file into fixed-size chunks, processes chunks independently using worker threads, and is intended to restore chunk order before producing the final compressed stream.
For this coding-progress stage, a Python prototype has been developed for the initial processing path. The implemented prototype demonstrates memory-mapped input, fixed-size chunking, a bounded producer–consumer queue, multiple worker threads, and independent DEFLATE compression. The remaining output-ordering and shutdown modules are planned for later stages.
